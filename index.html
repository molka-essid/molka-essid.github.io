Divalto HAL

End-of-studies project at INFO'LIB, Feb to Sep 2026. Sole engineer.

An assistant that answers questions about the Divalto ERP from its official documentation. Users ask in plain language; HAL routes the question to the right knowledge base, retrieves and reranks passages, checks that its answer is supported by them, and escalates to a human when it can't be sure.

I built every layer: the Confluence ingestion pipeline, the indexes, the LangGraph agents, the evaluation harness, and an authenticated FastAPI and Docker backend with a web app that exposes each routing, retrieval and verification decision.

  • 18,157passages indexed across two knowledge bases
  • 1,643Confluence pages extracted via REST APIs
  • 6 agentsorchestrated in LangGraph behind a semantic router
  • +17%faithfulness from cross-encoder reranking

Python, LangGraph, ChromaDB, sentence-transformers, cross-encoders, FastAPI, Docker
